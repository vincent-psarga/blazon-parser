# Fonts

`archivo-narrow-latin.woff2` and `archivo-narrow-latin-ext.woff2` are the latin and
latin-ext subsets of **Archivo Narrow**, a variable font by Omnibus-Type.

They are **not** covered by this project's MIT licence. They are licensed under the
SIL Open Font License 1.1, reproduced in full in `OFL.txt` alongside them:

> Copyright 2019 The Archivo Narrow Project Authors
> https://github.com/Omnibus-Type/ArchivoNarrow

No Reserved Font Name is declared, so these subsets — which are derivatives — may
carry the original name. They remain under the OFL, which permits bundling with
software under any other licence but never relicensing the font itself.

The font is used only by the demo. `package.json` ships `lib` alone, so the
published npm package contains no font.
